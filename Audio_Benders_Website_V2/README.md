# Audio Benders Company — Premium Storefront Prototype v2

Open `index.html` in a browser. Responsive dark minimalist storefront with DAW filters, four **illustrative** products, compatibility information, and checkout/demo placeholders.

## Launch checklist
1. Replace placeholder product names, descriptions, pricing, and product artwork with verified products.
2. Collect actual Pro Tools and FL Studio template files, supported versions, and exact Waves plugin lists (licenses not included).
3. Add rights-cleared before/after audio demos and verify each template on the supported DAW version.
4. Set up a merchant account and secure digital fulfillment (e.g. Shopify with a digital download app), and add live checkout URLs to `window.ABC_CHECKOUT_LINKS` before the main script. No payment keys or secrets in client-side HTML.
5. Configure refund terms, privacy policy, customer support, domain, hosting, HTTPS, receipts, and a successful test purchase.

Checkout buttons do not accept payments without configured URLs; demo buttons do not play fabricated audio. This is not yet a live store or delivery backend.
